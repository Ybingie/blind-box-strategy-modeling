# 公开计算数据说明

`market_prices_cleaned.csv` 保留 125 条计算用挂牌价格记录、款式索引、记录日期和匿名证据编号。它不是成交数据，不包含卖家姓名、联系方式或商品链接。

`market_data_audit_summary.csv` 保存原始 134 条记录、捆绑排除和价格缺失的分款计数。

`market_trace_audit.json` 保存 125 条基准与 122 条保守核查的价格中位数，以及重复链接和日期异常的汇总。它是内部记录核查结果，不是来源真实性证明。

`market_record_index_public.csv` 是公开版匿名索引：保留款式、记录号、日期、价格和不透明的挂牌组号；删除原工作簿路径、原表名、商品 URL 和截图文件名。不同款式可能来自同一挂牌组，不能假定每行是独立卖家。

## 已知问题

- 可计算记录有 125 个不同编号，对应原登记的 114 个不同商品链接；公开版不提供这些链接。
- MKT-068 与 MKT-075 同款且同链接组。
- MKT-126 日期登记为 2025-08-19，其他 124 条为 2026-08-05 至 2026-08-19。年份尚未解决，未擅自修正。
- 保守核查同时排除上述三条记录，其余 122 条记录的固定最优次数变为两次。
- 原始截图没有随公开仓库提供，完整搜索词、排名和卖家去重资料不可重建。

Bootstrap 是逐款、逐行的样本内重抽样，不能消除选择偏差、挂牌与成交差异或同卖家依赖。概率扰动是构造情景，不是产品抽取概率的测量。

公开计算记录保持原值；不通过虚构链接或日志填补缺口。本仓库的可复现范围是给定这些输入的数值计算，不是原始市场采样过程的完整重演。
