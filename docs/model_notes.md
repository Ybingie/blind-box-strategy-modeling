# 模型公式与解释

## 固定次数

对款式 i，抽取概率为 p_i，补购价格为 b_i，重复款期望回收为 r_i。预先确定抽数 k 后：

```text
E[C(k)] = k*c + Σ b_i*(1-p_i)^k
          - Σ r_i*(k*p_i - 1 + (1-p_i)^k)
```

等概率时，重复抽取的边际补购收益递减，固定最优通过相邻次数成本差确定。

## 动态停止

U 为缺失款式集合。下一抽的期望经济收益为：

```text
G(U) = Σ_missing p_i*b_i + Σ_owned p_i*r_i
```

候选规则是 G(U)>c 时继续，否则停止。Bellman 模型另行计算最优剩余成本；消去重复款造成的状态自循环后，继续值的分母为获得新款概率 q(U)。

当概率固定且为正、价格与回收固定、b_i≥r_i、c>Σp_i*r_i、完成为终点且目标是加性期望成本时：

```text
G(U\{i}) = G(U) - p_i*(b_i-r_i) ≤ G(U)
```

停止区域因此对后继状态封闭，可用逆推证明候选规则达到 Bellman 最优。等概率不是这个证明的必要条件。硬预算、非线性风险效用、价格变化或转售收益随库存变化不在该证明范围内。

## 风险

购买支出 A 等于盲抽支出加缺款补购；最终净成本 C=A-Y，Y 为实际净转售回收。两者的超支概率不同。当前程序评价风险，但没有直接优化预算约束或尾部风险目标。

## 结果的复现层次

- 闭式期望与状态递推：给定输入下的确定性量。
- Monte Carlo：有限样本估计，快速与正式运行不应混用。
- 价格 Bootstrap：当前方便样本内的变化，不是市场总体最优策略概率。
- 概率扫描：前四款与后四款间的有限概率转移，不是全部概率向量的不确定性分析。
- 清洗与异常核查：与已登记记录一致，不等于原始页面真实性验证。
