# 上传文件范围

将本包解压后的内容放到目标仓库根目录，保留 `.gitignore`、`src/`、`data/`、`docs/` 及各运行文件。

远程仓库地址：`git@github.com:Ybingie/blind-box-strategy-modeling.git`。

## 包内保留

- 最新模块化求解和绘图程序，以及一键入口。
- 必要的清洗价格 CSV 与审计 JSON。
- 不含商品链接的匿名记录索引。
- 中文学习型说明、公式解释、运行命令和依赖清单。
- 不绘图的基准核验入口。

## 包内不包含

- 原始 Excel 和完整中英文报告。
- 账号凭证、个人电脑路径、商品链接、截图文件名和原始截图。
- 历史代码、临时编译文件、Python 缓存和虚拟环境。
- 自动生成的高分辨率图、表格和模拟结果；这些可以在本地运行生成。
- 依赖原始文件的溯源重建脚本。

## 发布前保留的边界

不要将匿名索引描述成已验证的公开来源证据；没有原始截图不能补造。不要添加未经核实的作者贡献、独立完成或学校背书。代码和数据的公开可见性不等于已经授予开源许可，本包没有代选许可证。

`.gitignore` 不会阻止手动上传已经选中的生成文件，也不会自动移除仓库已跟踪的文件；因此上传时仍需检查范围。
