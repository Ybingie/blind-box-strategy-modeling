# 随机盲抽收集：成本、风险与动态停止

一个从生活中的收藏决策出发的数学建模项目。以八款徽章为案例，研究何时停止随机购买、转向二手市场补齐，并比较最低平均成本与较低超支风险之间的区别。

本仓库是报告配套的求解与绘图工具，不包含报告正文或原始商品页面截图。它使用已清洗的挂牌价格记录和明确设定的情景参数，不是实时价格服务或实际购买建议。

## 模型逐步解决什么问题

1. 完全二手购买与一直抽到齐：建立成本边界和 Coupon Collector 基准。
2. 固定停止：预先确定抽取次数，计算缺款补购和重复款转售。
3. 动态停止：根据已获得款式的身份决定是否继续，而不只看抽数。
4. Bellman 验证：逐状态比较一步规则与动态规划。
5. Monte Carlo：分析均值、分位数和最终净成本超支概率。
6. 敏感性与 Bootstrap：检验价格、转售、交易摩擦和概率偏差的影响。
7. 数据异常核查与现金风险：区分原始 125 条记录和 122 条保守核查，以及购买支出与转售后净成本。

## 快速开始

需要 Python 3.9 或更新版本（本次以 Python 3.9、NumPy 1.26.4、Matplotlib 3.8.4 核验）。建议先建立虚拟环境。安装依赖后，在仓库根目录运行：

```bash
python -m pip install -r requirements.txt
python run_final.py --quick --language en
```

快速模式每种随机策略模拟 10,000 次，价格 Bootstrap 重抽样 500 次；仍执行完整理论、256 状态与 51 个概率情景检验。

报告级运行：

```bash
python run_final.py
```

默认每种随机策略模拟 100,000 次、Bootstrap 2,000 次，生成中英文两版图。图件语言可以手动指定：

```bash
python run_final.py --language zh
python run_final.py --language en
python run_final.py --language both
```

无需网络请求、API 密钥、原始 Excel 或 LaTeX 环境。生成全部高分辨率图件需要一定运行时间。

如需采用本次核验的依赖版本，可将安装命令改为 `python -m pip install -r requirements-reproducible.txt`。这固定两个直接依赖，不是所有操作系统和字体环境的完整锁定。

## 配置与适用范围

参数集中在 `src/gacha_model/config.py` 的 `ModelConfig`：款式价格、概率、单抽成本、转售成功率、手续费、运费、卖方成本、预算参考线和随机种子均为手动配置。

当前是**八款案例的可复现工具**，不是任意产品的通用优化库。主入口中的基准回归断言、两款状态图、分组概率情景以及集齐公式具有案例条件：

- 基准 `validate_results` 断言固定最优为三次、动态均值为 356.715581 元等已知结果。改变基准参数后须检查并更新这些回归目标，不要把断言失败误认成所有求解公式失效。
- 集齐理论使用等概率公式；不能直接用于非均匀概率。概率扰动模块只重算固定、动态与 Bellman 结果。
- 记录排除核查沿用 `market_trace_audit.json` 的两套价格中位数，不能视为任意新数据的自动清洗器。
- 固定最优次数是在 `0..fixed_k_max` 中搜索；扩大适用范围时应检查最优值没有落在截断上界。

## 输出

所有结果生成到仓库内的 `outputs/`，不会写入仓库的父目录。

| 目录 | 内容 |
|---|---|
| `figures_zh/main/`、`figures_en/main/` | 每种语言 15 张正文图，PNG、SVG、PDF 三格式 |
| `figures_zh/appendix/`、`figures_en/appendix/` | 每种语言 11 张附录诊断图 |
| `tables/` | 策略成本与风险、动态状态、概率敏感性、Bootstrap、现金支出和 LaTeX 三线表 |
| `summary/` | 参数、模型摘要及验证结果 |

两种语言共用同一批计算数组，仅切换可见文本；快速模式不能替代报告中的正式模拟数值。`outputs/` 默认由 `.gitignore` 排除，避免重复提交大型生成文件。

## 核心结果与学习重点

默认案例的理论结果为：

| 策略 | 期望净成本（元） |
|---|---:|
| 完全二手购买 | 366.58 |
| 固定两次 | 357.59 |
| 固定三次 | 357.31 |
| 动态停止 | 356.72 |
| 一直抽到齐 | 571.95 |

动态策略平均抽数为 2.6190；它在 28 个“已获得两款”的状态中继续 10 个、停止 18 个。动态均值优势很小，因此报告还比较风险和价格不确定性，而不只给出一个最小值。

固定两次的精确净成本超 400 元概率为 3.4375%，转售前购买支出超 400 元概率为 6.25%。后者仍不是完整付款时序模型，也不是硬预算可行性保证。

## 不绘图的核验入口

```bash
python verify_model.py
```

该入口检查默认案例的固定、动态、Bellman、概率情景、精确现金风险以及公开数据的价格中位数与排除核查，不写入输出目录。正式入口另包含模拟均值核验和图件数量核验。

## 数据与证据边界

见 [数据说明](data/README.md)。125 条价格为挂牌方便样本，不是成交随机样本；概率、转售和若干成本参数是情景假设。公开版已移除商品链接、截图文件名及原工作簿路径，保留匿名记录和链接组号用于说明依赖性。不要称这些编号是可公开查验的原始截图证据。

没有将项目内部依赖原始 Excel 的 `build_market_trace.py` 放入仓库。主入口不需要它。

## 字体与跨平台运行

中文图需要系统提供微软雅黑、黑体、苹方、Noto Sans CJK SC 或思源黑体之一。缺少这些字体时中文可能显示为方框；可以先使用 `--language en`。无桌面环境运行时可设置 `MPLBACKEND=Agg`。字体和依赖版本可能影响图的外观，随机模拟也应允许浮点与版本差异，不要求图文件逐字节一致。
